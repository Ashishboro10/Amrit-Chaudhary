# Amrit-Chaudhary
ATM system in Java with Azure — secure login, deposits/withdrawals, balance check; CLI demo with basic validations and tests.
This project is a simple ATM system built in Java with basic Azure integration for deployment practice. It supports user authentication, validated deposits/withdrawals, and real-time balance checks through a clean CLI. The goal is to demonstrate core OOP structure, input validation, and lightweight testing while keeping the code readable and easy to run.
